```
├── figures/                 — SVG/PNG для встройки
└── Diplom_2026.docx         — финальный собранный документ (генерируется)
```

## Workflow

1. Главы пишутся в markdown в `chapters/`
2. Скрипт `tools/build_diploma.js` собирает их в финальный `.docx`
3. Эксперименты запускаются через `tools/run_extended_experiments.py`,
   результаты пушатся в `experiments/`
4. Диаграммы рендерятся в SVG через matplotlib (`tools/render_diploma_figures.py`)
