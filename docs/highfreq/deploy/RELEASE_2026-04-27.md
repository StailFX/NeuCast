# Release 2026-04-27 — Defence-grade hardening

5 features, 50 new tests (392 total green). All defence-prep oriented;
none of them change live trading semantics — purely additive.

## What's new

| # | Feature | Files |
|---|---|---|
| 1 | **One-sided binomial p-value** in training report (H₀ "no skill") | `app/highfreq/trainer.py`, `app/highfreq/predictor.py` |
| 2 | **Cron-failure alerts** via node_exporter textfile_collector | `app/highfreq/cron_metrics.py`, alerts.yaml, instrumentation in archive_l2 / prom_backup / trainer |
| 3 | **DR drill tooling** — read-back of L2 archives from S3, schema validation, optional restore-into-test-table | `tools/dr_drill_l2.py`, `docs/highfreq/dr_drill.md` |
| 4 | **Realized rolling accuracy** — production trader's actual hit rate vs CV | `app/highfreq/realized_accuracy.py`, runner hook, `/api/highfreq/realized_accuracy` endpoint, Prometheus gauge |
| 5 | **Frozen holdout** — last 7 days never seen by trainer; weekly OOS eval script | `app/highfreq/trainer.py` (config + partition), `tools/eval_frozen_holdout.py`, holdout-eval timer/service |

## Tokyo deployment steps

Run all of these as the existing deploy user. None require service restarts
beyond the trainer/paper-trader rolls.

### 1. Pull new code

```bash
cd /opt/neucast
sudo -u neucast git fetch origin main
sudo -u neucast git pull --ff-only origin main
sudo -u neucast /opt/neucast/venv/bin/pip install -r docs/highfreq/deploy/requirements-highfreq.txt
```

scipy is a transitive dep of scikit-learn (already installed) — no
new top-level packages required.

### 2. Set up textfile_collector dir for cron heartbeats

If node_exporter is already running with `--collector.textfile.directory`,
verify the path; otherwise create it:

```bash
sudo mkdir -p /var/lib/node_exporter/textfile_collector
sudo chown neucast:neucast /var/lib/node_exporter/textfile_collector
sudo chmod 0755 /var/lib/node_exporter/textfile_collector
```

Confirm node_exporter is configured to scrape this dir:

```bash
sudo systemctl cat prometheus-node-exporter | grep -i textfile
# Expected: --collector.textfile.directory=/var/lib/node_exporter/textfile_collector
```

If the flag isn't there, add it via systemd drop-in:

```bash
sudo systemctl edit prometheus-node-exporter
# Add to the unit:
#   [Service]
#   ExecStart=
#   ExecStart=/usr/bin/prometheus-node-exporter \
#       --collector.textfile.directory=/var/lib/node_exporter/textfile_collector
sudo systemctl restart prometheus-node-exporter
```

### 3. Roll the always-on services to pick up code changes

```bash
sudo systemctl restart neucast-highfreq-web.service
sudo systemctl restart 'neucast-paper-trader@*.service'
```

Trainer + holdout-eval timers fire on schedule — no restart needed.

### 4. Install the new holdout-eval timer/service (per symbol)

```bash
sudo cp docs/highfreq/deploy/neucast-highfreq-holdout-eval@.service /etc/systemd/system/
sudo cp docs/highfreq/deploy/neucast-highfreq-holdout-eval@.timer   /etc/systemd/system/
sudo systemctl daemon-reload

for sym in btcusdt ethusdt bnbusdt; do
  sudo systemctl enable --now "neucast-highfreq-holdout-eval@${sym}.timer"
done

sudo systemctl list-timers 'neucast-highfreq-holdout-eval@*'
```

First firing is the next Monday at 04:30 UTC. To produce a baseline now:

```bash
for sym in btcusdt ethusdt bnbusdt; do
  sudo systemctl start "neucast-highfreq-holdout-eval@${sym}.service"
done
journalctl -u 'neucast-highfreq-holdout-eval@btcusdt.service' --since "5 min ago"
```

### 5. Reload Grafana alert rules

```bash
sudo cp docs/highfreq/deploy/grafana/alerting/alerts.yaml \
        /etc/grafana/provisioning/alerting/alerts.yaml
sudo systemctl restart grafana-server
```

Verify the 3 new alerts are registered:

```bash
curl -s -u admin:<pass> http://127.0.0.1:3000/api/v1/provisioning/alert-rules \
  | jq '.[] | select(.uid | test("(l2-archive|prom-backup|trainer)-stale-rule")) | .title'
```

Expected output:
```
"L2 archive cron hasn't succeeded in >25h"
"Prometheus backup cron hasn't succeeded in >25h"
"HF trainer hasn't succeeded for some symbol in >25h"
```

### 6. Sanity-check the new endpoints + metrics

# New endpoint
curl -s 'https://neucast.ru/api/highfreq/realized_accuracy?symbol=BTCUSDT&window=100' | jq

# New Prometheus metrics surfacing

### 7. (Recommended) First DR drill

After steps 1-6 land, run a baseline drill while the deploy is still
fresh — captures the "we shipped this and verified S3 still works"
checkpoint:

```bash
cd /opt/neucast
sudo -u neucast bash -lc '
  set -a
  source /etc/default/neucast-l2-archive
  set +a
  python -m tools.dr_drill_l2 --day "$(date -u -d yesterday +%F)"
' | tee "docs/highfreq/dr_drill_runs/$(date -u +%F).json" \
  | jq '.overall_ok, (.results[] | {symbol, rows_in_parquet, schema_ok})'
```

Expected: `overall_ok: true`, `schema_ok: true` for all 3 symbols.

Commit the drill output:

```bash
git add docs/highfreq/dr_drill_runs/*.json
git commit -m "docs: first post-release DR drill output"
```

## Rollback

The release is fully additive. To roll back any single feature without
reverting the whole commit:

* **p-value** — predictor reads `dir_acc_p_value` via `.get()` so old
  trainers are forward-compat. To remove from UI: just don't read it.
* **Cron alerts** — delete the 3 new rules from `alerts.yaml` and
  reload Grafana. Heartbeats keep being written but go unmeasured.
* **DR drill** — read-only by default. If `--restore-into-table` was
  used, drop the test table: `DROP TABLE highfreq_l2_snapshots_dr_test`.
* **Realized accuracy** — to disable the gauge updates, comment out
  the import block in `paper_trader_runner.py`. The endpoint still
  works (reads paper_trades directly).
* **Frozen holdout** — pass `--frozen-holdout-days 0` on the trainer
  CLI (or set the env var). The trainer goes back to seeing all data.
